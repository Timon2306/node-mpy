# Node-MPY — MicroPython Visual Flow Studio

Визуальная среда блочного программирования для **MicroPython** (ESP32, ESP8266, Raspberry Pi Pico). Спроектирована на стеке **Tauri v2 + React 18 (TypeScript) + React Flow (@xyflow/react) + TailwindCSS + Zustand + Rust**.

Приложение работает **кроссплатформенно на Linux, macOS и Windows**: как в виде легковесного веб-приложения в любом браузере, так и в виде нативного десктопного приложения через Tauri v2.

---

### Фирменный стиль (Deep Slate & Electric Teal)
* **Холст:** тёмный графит `#12161F` с точечной сеткой макетной платы `#1E2433`.
* **Сайдбары и панели:** `#161B26` с тонкими рамками `#262F40`.
* **Главный акцент (кнопка «Export main.py»):** `#00D4B2` (Electric Teal).
* **Цветовое кодирование разъёмов (сокетов):**
  * `flow` (Очередность выполнения): **Белый** (`#FFFFFF`)
  * `pin` (Аппаратный пин `machine.Pin`): **Изумрудный** (`#10B981`)
  * `bus` (Шины I2C, SPI): **Фиолетовый** (`#8B5CF6`)
  * `device` (Экран / Датчик / Мотор): **Оранжевый** (`#F59E0B`)
  * `number` (Числа int/float): **Голубой** (`#3B82F6`)
  * `boolean` (True/False): **Розовый** (`#EC4899`)
  * `string` (Текст): **Желтый** (`#EAB308`)

## Как запускать

### Вариант 1: Запуск в браузере (Web-версия)
Не требует сборки Rust или установки системных библиотек GTK. Работает в любом современном браузере:

```bash
# Установка зависимостей (один раз)
npm install

# Запуск локального сервера разработки
npm run dev
```
После этого откройте в браузере: `http://localhost:1420`.

Для сборки автономной статической версии:
```bash
npm run build
npm run preview
```

### Вариант 2: Запуск в виде десктопного приложения (Tauri v2)
```bash
# Запуск в десктопном окне
npm run tauri dev

# Сборка установочного пакета (.deb/.AppImage для Linux или .exe NSIS для Windows)
npm run tauri build
```

## Декларативный JSON-реестр (Zero Hardcode)

Все библиотеки и ноды описаны в чистом **JSON-формате** и находятся в каталоге `src/registry/definitions/`:

### Встроенные (Native MicroPython, первый приоритет):
1. **`core.json`** — Базовая логика (`Import Module`, `Start/Init`, `While True Loop`, `If/Else`, `Comparison`, `Math`, `Map Range`, `Print`, `Custom Function`).
2. **`machine.json`** — Управление `Pin` (IN/OUT/PULL_UP), `PWM` (частота/скважность), `ADC` (АЦП), `I2C Bus Init`, `SPI Bus Init`, `Reset`.
3. **`time.json`** — Задержки `sleep_ms`, `sleep_s`, замеры времени `ticks_ms`, `ticks_diff`.
4. **`network.json`** — Подключение к Wi-Fi сети (`WLAN STA`) и проверка соединения.
5. **`dht.json`** — Датчики температуры и влажности DHT11 / DHT22.
6. **`neopixel.json`** — Адресные светодиодные ленты и кольца WS2812B.

### Внешние драйверы (из репозитория `BoardyPy`):
1. **`ssd1306.json`** — Монохромные OLED дисплеи 128x64 и 128x32 по I2C.
2. **`st7735.json`** — Цветные графические TFT экраны 128x160 по SPI.
3. **`bmp280.json`** — Датчик давления, температуры и высоты по I2C.
4. **`servo.json`** — Управление сервоприводами SG90 / MG996R (угол 0–180°).
5. **`i2c_lcd.json`** — Символьные дисплеи LCD 1602 и 2004 через I2C адаптер PCF8574.
6. **`max7219.json`** — Светодиодные матрицы 8x8 по SPI.

## Генерация новых нод через стороннюю нейросеть (AI Prompt Template)

В приложении реализовано окно **«Управление палитрой»** (кнопка `Палитра` в левом сайдбаре или в меню `☰`):

1. Перейдите во вкладку **«Промпт для ИИ»** и нажмите **«Скопировать промпт»**.
2. Откройте ChatGPT, Claude, DeepSeek или любую другую нейросеть, вставьте скопированный промпт и прикрепите свой `.py` файл MicroPython библиотеки.
3. Нейросеть сгенерирует готовый JSON.
4. Вставьте полученный JSON во вкладку **«Импорт JSON»** — и новые ноды моментально появятся в палитре и сохранятся в вашем браузере!

## Генерация кода main.py
Компилятор пересчитывает схему при любом соединении блоков и формирует скрипт. Пустые разделы в него не попадают:
1. Импорты
2. `# --- Оборудование ---`
3. `# --- Функции ---`
4. `# --- Программа ---`

Нажмите кнопку **«Export main.py»**, чтобы скачать готовый скрипт для контроллера. Ноды, которые не попадут в код или не смогут работать, отмечаются на холсте предупреждением.

## Дашборд
Дашборд собирается без проводов: у виджета указывается **имя** (поле «Имя показаний» у шкалы, графика, текста и индикатора, «Имя связи» у тумблера, ползунка и кнопки), и то же имя вписывается в ноде «Отправка в Дашборд» в прошивке. Например, шкала с именем `light` показывает то, что плата отправила на `light`. Провода и `HTTP Endpoint` нужны только для сложных случаев: `Function`, `HTTP Response`.

У каждого тумблера и ползунка свой **канал**. В ответ на запрос ESP получает все каналы сразу, например `{"relay":"RELAY_ON","pwm":500}`, поэтому команды не затирают друг друга. Если поле канала пустое, оно назначается само: `switch1`, `slider1`. Кнопки по умолчанию делят канал `buttons`.

В прошивке:
* **«Отправка в Дашборд»** отправляет показания и получает все команды. Поле IP можно оставить пустым: подставится адрес этого компьютера.
* **«Проверка команды»** проверяет, есть ли нужная команда среди текущих.
* **«Значение канала»** читает значение одного тумблера или ползунка по имени канала.

Если выход `Request` у `HTTP Endpoint` соединён с нодой `HTTP Response`, ESP получит этот ответ вместо списка каналов.

Кнопка **«Запустить дашборд»** открывает окно дашборда. Кнопка **«Запустить сервер»** в нём поднимает сервер прямо в приложении (порт 1880): плата и телефон подключаются по адресу `http://<IP компьютера>:1880`, статус «ESP на связи» настоящий. Windows при первом запуске спросит про доступ к сети, его нужно разрешить. Экспорт `server.ts` остаётся как запасной вариант (`npx tsx server.ts`).

В ноде «Отправка в Дашборд» имя можно выбрать из списка имён, уже заданных на вкладках дашборда.

## Плата
Кнопка **«На плату»** заливает `main.py` и нужные драйверы (экраны, датчики) по USB и показывает `print()` платы. Порт определяется сам. Закройте BoardyPy и Thonny, пока заливаете.

Готовые примеры (датчик света, светодиод, ШИМ) лежат в меню добавления вкладки. Пины I2C и SPI по умолчанию подходят для ESP8266.

Сервер и заливка по USB проверены только компиляцией Rust-кода, на реальной плате и в собранном приложении их ещё нужно проверить.
