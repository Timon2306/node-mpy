# Node-TEAL — MicroPython Visual Flow Studio

Визуальная среда блочного программирования в эстетике **Node-RED** специально для **MicroPython** (ESP32, ESP8266, Raspberry Pi Pico). Спроектирована на стеке **Tauri v2 + React 18 (TypeScript) + React Flow (@xyflow/react) + TailwindCSS + Zustand + Rust**.

Приложение работает **кроссплатформенно на Linux и Windows**: как в виде легковесного веб-приложения в любом браузере (на парах в колледже), так и в виде нативного десктопного приложения через Tauri v2.

---

### Фирменный стиль (Deep Slate & Electric Teal)
* **Холст:** тёмный графит `#12161F` с точечной сеткой макетной платы `#1E2433`.
* **Сайдбары и панели:** `#161B26` с тонкими рамками `#262F40`.
* **Главный акцент (кнопка «Export main.py»):** `#00D4B2` (Electric Teal).
* **Цветовое кодирование разъёмов (сокетов):**
  * `flow` (Очередность выполнения): **Белый** (`#FFFFFF`)
  * `pin` (Аппаратный пин `machine.Pin`): **Изумрудный** (`#10B981`)
  * `bus` (Шины I2C, SPI): **Фиолетовый** (`#8B5CF6`)
  * `device` (Экран / Датчик / Мотор): **Оранжевый** (`#F59E0B`)
  * `number` (Числа int/float): **Голубой** (`#3B82F6`)
  * `boolean` (True/False): **Розовый** (`#EC4899`)
  * `string` (Текст): **Желтый** (`#EAB308`)

## Как запускать

### Вариант 1: Запуск в браузере (идеально для Linux на парах в колледже)
Не требует сборки Rust или установки системных библиотек GTK. Работает в любом современном браузере:

```bash
# Установка зависимостей (один раз)
npm install

# Запуск локального сервера разработки
npm run dev
```
После этого откройте в браузере: `http://localhost:1420`.

Для сборки автономной статической версии:
```bash
npm run build
npm run preview
```

### Вариант 2: Запуск в виде десктопного приложения (Tauri v2)
```bash
# Запуск в десктопном окне
npm run tauri dev

# Сборка установочного пакета (.deb/.AppImage для Linux или .msi/.exe для Windows)
npm run tauri build
```

## Декларативный JSON-реестр (Zero Hardcode)

Все библиотеки и ноды описаны в чистом **JSON-формате** и находятся в каталоге `src/registry/definitions/`:

### Встроенные (Native MicroPython, первый приоритет):
1. **`core.json`** — Базовая логика (`Import Module`, `Start/Init`, `While True Loop`, `If/Else`, `Comparison`, `Math`, `Map Range`, `Print`, `Custom Function`).
2. **`machine.json`** — Управление `Pin` (IN/OUT/PULL_UP), `PWM` (частота/скважность), `ADC` (АЦП), `I2C Bus Init`, `SPI Bus Init`, `Reset`.
3. **`time.json`** — Задержки `sleep_ms`, `sleep_s`, замеры времени `ticks_ms`, `ticks_diff`.
4. **`network.json`** — Подключение к Wi-Fi сети (`WLAN STA`) и проверка соединения.
5. **`dht.json`** — Датчики температуры и влажности DHT11 / DHT22.
6. **`neopixel.json`** — Адресные светодиодные ленты и кольца WS2812B.

### Внешние драйверы (из репозитория `BoardyPy`):
1. **`ssd1306.json`** — Монохромные OLED дисплеи 128x64 и 128x32 по I2C.
2. **`st7735.json`** — Цветные графические TFT экраны 128x160 по SPI.
3. **`bmp280.json`** — Датчик давления, температуры и высоты по I2C.
4. **`servo.json`** — Управление сервоприводами SG90 / MG996R (угол 0–180°).
5. **`i2c_lcd.json`** — Символьные дисплеи LCD 1602 и 2004 через I2C адаптер PCF8574.
6. **`max7219.json`** — Светодиодные матрицы 8x8 по SPI.

## Генерация новых нод через стороннюю нейросеть (AI Prompt Template)

В приложении реализовано окно **«Управление палитрой»** (кнопка `Палитра` в левом сайдбаре или в меню `☰`):

1. Перейдите во вкладку **«Промпт для ИИ»** и нажмите **«Скопировать промпт»**.
2. Откройте ChatGPT, Claude, DeepSeek или любую другую нейросеть, вставьте скопированный промпт и прикрепите свой `.py` файл MicroPython библиотеки.
3. Нейросеть сгенерирует готовый JSON.
4. Вставьте полученный JSON во вкладку **«Импорт JSON»** — и новые ноды моментально появятся в палитре и сохранятся в вашем браузере!

## Генерация кода main.py
Компилятор автоматически пересчитывает граф при любом соединении блоков и формирует чистый скрипт по 4 секциям:
1. `# --- 1. IMPORTS ---`
2. `# --- 2. HARDWARE & OBJECTS INIT ---`
3. `# --- 3. FUNCTIONS & CALLBACKS ---`
4. `# --- 4. MAIN EXECUTION & LOOP ---`

Нажмите яркую кнопку **«Export main.py»** для скачивания готового скрипта для контроллера.
